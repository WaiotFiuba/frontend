## frontend

React + TypeScript + Vite.

Requisitos:
- Node 24+
- npm

Comandos principales:

- Instalar dependencias (local):

```bash
npm install
```

- Ejecutar linter:

```bash
npm run lint
```

- Ejecutar tests:

```bash
npm test
```

- Servidor de desarrollo (hot-reload):

```bash
npm run dev
```

- Compilar para producción:

```bash
npm run build
```

- Previsualizar build:

```bash
npx vite preview
```
